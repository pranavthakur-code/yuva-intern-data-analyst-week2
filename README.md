# yuva-intern-data-analyst-week2
Data Science Lab Hands-on lab: environment setup, data cleaning, visualization and basic analysis on a synthetic retail sales dataset (500 orders, fixed random seed).

Run
pip install numpy pandas matplotlib seaborn scipy scikit-learn jupyter
jupyter notebook Data_Lab.ipynb

Contents
- Data_Lab.ipynb: full code and outputs
- sales_raw.csv: generated raw data (with duplicates and missing values)
- fig_*.png: charts used in the report
